# figcut

**在 PDF 试卷上圈图，导出干净的白底 PNG。**

画一个矩形或多边形 → 自动缩到框内的墨迹 → 只往白里加边距 → 按题号/角色命名导出。
不上传、不起服务、不装依赖；打开浏览器就能用。

---

## 快速开始

1. 打开 `figure-workbench.html`（双击，或放到任意静态服务器上）。
2. 拖入 PDF，或点左上角「打开」。
3. 用 **矩形 (R)** / **多边形 (G)** 圈住图。
4. 在右栏设 **类型**（题干 / A–K 可多选 / 自定义）、**题号**、**备注**。
5. `Ctrl+E` 导出 ZIP：每张图一个 PNG + `figure-regions.json`。

第一次打开需要联网（pdf.js 走 CDN，版本钉死）。之后同一页面内不再请求。

---

## 它解决什么

- **框内自动缩紧**：只统计多边形内的非白像素，蓝框画歪一点没关系，导出框会贴到图上。
- **边距只往白里长**：默认 8pt，碰到相邻的线/文字就停，不会把隔壁题拖进来。
- **多边形就是蒙版**：选区外的像素涂白，框外的文字不会出现在导出图里。
- **放大不糊**：导出按 DPI（默认 300）重新渲染，不是截屏放大。

## 界面

| 位置 | 内容 |
| --- | --- |
| 顶栏左 | 打开 / 撤销 / 重做 / 选择·矩形·多边形 |
| 顶栏右 | 配色三连体（浅UI浅PDF / 深UI浅PDF / 深UI深PDF）、导出设置（DPI、边距）、导出 |
| 左栏 | 页面缩略图（单/双列切换、全览、全屏看大图、每页标注数） |
| 右栏 | 每个 figure 的缩略图、拖动排序、类型/题号/备注、删除；选中后可点缩略图全屏预览 |
| 右下 | 缩放：− [档位 ▾] +，档位含 25%–500% 与实时的「页宽 %」 |

手机/平板上侧栏默认收起，点底角箭头展开。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `V` / `R` / `G` | 选择 / 矩形 / 多边形 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+E` | 导出 ZIP |
| `Ctrl+O` | 打开 PDF |
| `Ctrl` + 滚轮 | 缩放（只落在档位上，含实时页宽） |
| `Esc` | 关闭全屏预览 |

## 导出命名

`p{页:02}-q{题号}-{角色}-{备注}.png`

- 角色：`stem` / `optA` / `optA-optC`（多选）/ `opt自定义名`
- 没填题号是 `q00`，非法字符与空格压成下划线
- ZIP 写 UTF-8 标志位，中文备注解压不乱码

例：`p09-q28-optB-第二行.png`

## 架构

零依赖 ESM，分层 `core / pdf / view / ui / io / app`，`build.py` 按拓扑序把模块内联成单个 HTML。

```
src/core/    几何、墨迹掩膜、命名、布局计算（纯函数，全部有测试）
src/pdf/     pdf.js 封装：打开、渲染、文本层
src/view/    页面栈、选区编辑器、覆盖层、缩放
src/ui/      顶栏、侧栏、检查器、缩放控件
src/io/      导出 PNG/ZIP、文件句柄、最近文件
src/app/     启动装配、导出流程
```

```bash
python3 build.py          # 生成 figure-workbench.html
node tools/unit.mjs       # 单元测试（149 passed）
python3 serve.py 8766     # 开发用静态服务
node tools/stress.mjs tmp/corpus/m.pdf 1,2,5   # 真 PDF 压测
```

pdf.js 通过 CDN 加载：`pdfjs-dist@3.11.174`（unpkg），worker 同版本。

## 数据存放

- `localStorage`：`figcut.regions`（按 文件名|字节数 存标注）、`figcut.settings`、`figcut.layout`、`figcut.theme`、`figcut.recent`
- `IndexedDB` `figcut`：最近文件的 FileSystemHandle 与 PDF 字节缓存（被挤出最近列表即删除）
- 换文件会清空内存里的掩膜缓存；标注跟着文件走

---

## 已知限制

- 只处理单个 PDF；不做批量队列、不做 OCR
- 圈图靠手，没有自动切图
- 浏览器不支持 File System Access API 时，「最近打开」需要重新选一次文件（字节缓存命中时不需要）
