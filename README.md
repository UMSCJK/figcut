# figcut

离线单文件 PDF 图区提取工作台：在试卷 PDF 上手动框出**题干图**和 **A–D 选项图**，
导出 300 dpi 白底 PNG（按页/序号/类型命名）+ 一份 JSON 配置。

双击 HTML 就能用。不上传、不起服务、不装依赖、不联网。

---

## 为什么有这个东西

把 AEAS 数学题 PDF 变成题库时，最费时间的一步是把卷子里的图一张张抠出来：
一张 A4 页上可能有题干图 + 四个选项图，还要按题号命名、保证白底、保证不切到笔画。

通用截图工具做不到，因为它们只管框，不管"边界必须落在纯白行/列上、跨框的笔画要整根收进来"。
figcut 就是这个问题的专用工具。

---

## 形态

- **交付物**：一个 HTML（约 150–180 KB）+ 同目录 `vendor/pdfjs/`。
  自己的 JS/CSS 全部构建时内联进 HTML；pdf.js 保持外部 classic `<script src>`。
- **拷给别人**要连 `vendor/` 一起拷，只拷 HTML 会白屏。
- 支持 Chromium / Firefox 桌面版，`file://` 直开。
- 一次处理一个 PDF，不做批量队列。

### 为什么 pdf.js 文档在仓库里而不是走 CDN

验收要求"双击即用、零网络请求"。CDN 版本断网就白屏，而这工具的使用场景恰恰常常没网。
所以 `vendor/pdfjs/` 直接入库（Apache-2.0，1.4 MB）。

## 用法

1. 用浏览器打开构建产物 `figure-workbench.html`（或双击）。
2. 打开 / 拖入一个试卷 PDF。
3. 选「矩形」或「多边形」圈图；框就停在你画的位置，不会自己挪。
4. 选中框，设类型（题干 / A B C D）、题号、备注。
5. `Ctrl+E` 导出 ZIP：平铺的 `p01-01-stem.png` … + `figure-regions.json`。

快捷键：`V` 选择 `R` 矩形 `G` 多边形 `n/p` 翻页 `f/w` 适应 `Ctrl+E` 导出 `Ctrl+Z/Y` 撤销重做
`Ctrl+I` 预览反相 `F9` 侧栏 `F11` 全屏。完整列表见 `SPEC.md` 第 9 节。

## 开发

- 源码在 `src/`，按 `core / pdf / view / ui / io / app` 分层；纯逻辑（几何、白界框、布局、拖动）不碰 DOM，可在 node 下单测。
- 开发时用本地静态服务跑 ESM；**验收只看构建产物**，不看开发页。
- 构建把 `index.html` + `styles/` + `src/` 拓扑排序后内联成单文件 HTML，fail-fast：缺文件、缺导出、循环 import、语法错误直接失败。
